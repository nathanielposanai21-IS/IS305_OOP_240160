## 1. Project Description

The **DWU Dining Meal Booking** application is a Node.js console-based application developed for the DWU Dining Hall.

The application allows students to create meal bookings by entering their student information and selecting a meal type, meal date, quantity, and dietary requirements.

The system validates student and booking information, calculates the total meal cost, prevents duplicate bookings, assigns a default booking status, and displays a booking summary.

The application demonstrates important **Object-Oriented Programming (OOP)** concepts, including:

- Classes
- Objects
- Constructors
- Encapsulation
- Private fields
- Getters
- Setters
- Methods
- Object creation
- Input validation

# 2. System Features

The DWU Dining Meal Booking application provides the following features:

- Create a student object.
- Enter Student ID.
- Enter first name.
- Enter last name.
- Display student information.
- Create a meal booking.
- Select Breakfast, Lunch, or Dinner.
- Enter a meal date.
- Enter meal quantity.
- Enter dietary notes.
- Validate student information.
- Validate meal booking information.
- Calculate the total meal cost.
- Assign new bookings a **Pending** status.
- Confirm bookings.
- Cancel bookings.
- Prevent duplicate bookings.
- Display a booking summary.
- Store multiple bookings during the current program session.
- Allow the user to create another booking.
