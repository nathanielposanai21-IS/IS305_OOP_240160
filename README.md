## 📖 About

This repository contains my coursework, laboratory activities, assessments, and project work completed for **IS305 – Object-Oriented Programming**.

The unit introduces the principles of Object-Oriented Programming (OOP) using **JavaScript**, **Node.js**, **MongoDB**, and **GitHub**. Throughout the semester, students develop console-based applications while applying core OOP concepts such as classes, objects, encapsulation, inheritance, and polymorphism.
