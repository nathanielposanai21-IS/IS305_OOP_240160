# Project Overview

This project was developed as part of the IS305 Object-Oriented Programming course at Divine Word University.

The objective is to design and implement a **Node.js console-based application** that models a real-world student service subsystem using Object-Oriented Programming principles.

The application demonstrates:

- Object-Oriented Design
- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Exception Handling
- MongoDB Database Integration
- CRUD Operations
- GitHub Version Control

# Installation

Clone the repository

```bash
git clone https://github.com/nathanielposanai21-IS/IS305_OOP_240160
```

Navigate into the project

```bash
cd REPOSITORY
```

Install dependencies

```bash
npm install
```

Start MongoDB

```bash
mongod
```

Run the application

```bash
node app.js
```
